# ADR-007: 契约仿真端点（Cloudflare Worker）+ endpoint 可配置 + 超时/退避工程定案

- **状态**: 已接受 (Accepted)
- **日期**: 2026-09-24
- **关联**: `03` §2.1 / §3、`05` §2.2、`01` §2、`ADR-004`

## 背景

TypeSafe AI 于 2026-09-22 **暂停 Jev 注册**（存量账号可用，新用户不可注册，且有存量用户报告 Key 被拒）。`v0.1.1`（判定服务诚实化）原本依赖真实 Key 的两个环节——S2/S3 实测回填超时/退避、S7 真机验收——被外部阻塞，恢复时间不可控。

真实客户端的**代码路径**（HTTP、超时、重试、错误归一、密钥管理）不依赖真实账号即可实现；缺的只是「一个可连的端点」。

## 决策

1. **契约仿真端点**：新增 `tools/jev-mock/`（仓库根），以 Cloudflare Worker 兼容模块（`export default { fetch }`，零运行时依赖）实现 `03` §2.1 的完整契约——本地 `npx wrangler dev` 起服务，`npx wrangler deploy` 一键部署到 Cloudflare Worker（`wrangler` 仅 devDependency）。
   故障注入经请求头 `x-jev-mock-fault: timeout | disconnect | http500 | rate429 | badschema`，分别对应 `ERR-02` / `ERR-01` / `ERR-03` / `ERR-04` / `ERR-05` 五类失败面。
2. **endpoint 可配置**：`CFG-01` 纯增量新增 `sonecheck.endpoint`（string，默认官方 `https://api.typesafe.ai/v1/systemone`）。T2 契约测试与 S7 真机验收均把该配置指向仿真端点；企业代理 / 自托管网关复用同一能力。
3. **超时/退避工程定案**：单请求超时 **400ms**、仅 `429` / `529` **重试 1 次**（退避 150ms），单请求链上界 ≈950ms < `00` §3 端到端 p95 ≤ 1s 预算。`03` §2.1 两处 TODO 翻案为「工程上限定案 + 真机校准待 Key 到位」注记。

## 原因

1. **代码全真，只差上游**：扩展侧一行假代码都不引入——真实 `fetch`、真实 `AbortController` 超时、真实退避、真实 SecretStorage；`IJevClient` 冻结签名（ADR-002）保证 Key 到位后零改动切真端点。
2. **Worker 是真实公网端点**：相较进程内拦截（MSW），仿真端点经真实 TLS / RTT / DNS，T2 与真机验收覆盖的网络栈更完整；且一处部署、多机可用，S7 验收无需本地常驻进程。
3. **endpoint 可配置本就是正当产品能力**：BYOK 的企业用户（`00` §2 US-04）常经网关代理出站请求，默认值保底、可覆盖为测试/自托管端点。
4. **数据不可得时的兜底合规**：`dev-meta/docs/02-version-rules.md` §6.3 允许实测不可得时以工程上限定案，但须显式登记依据并留复核触发——本 ADR 即该登记。

## 后果

✅ `v0.1.1` 可按期收口（VSIX + tag），不被外部注册状态阻塞
✅ T2 契约测试与 S7 真机验收对同一仿真端点执行，故障注入五类全覆盖
⚠️ **欠一次真实端点校准**（真实延迟分布、真实 429 行为）——显式挂账；Jev Key 到位后补测，若定案值变化只动 `src/constants.ts` 与 `03` 注记，不动结构
⚠️ 仿真端点与真实上游存在 schema 漂移风险——仿真实现以 `03` §2.1 为唯一权威，真实接入时以 T2 对照
🔧 `tools/jev-mock/` 不进 `.vsix`（`.vscodeignore` / `files` 排除）；`wrangler` 仅 devDependency，不违反运行期零依赖（`01` §2）
🔧 `CFG-01` 纯增量追加 `sonecheck.endpoint`（`03` §5 迁移策略）

## 替代方案

| 方案 | 否决原因 |
|---|---|
| 等 Jev 恢复注册再开版 | 阻塞时间不可控；工程准备工作本不依赖真实账号 |
| MSW 进程内拦截（仅测试内建） | extension host 的 undici 拦截兼容性有风险；真机验收没有可连端点，还得再引一层拦截 |
| 第三方 mock 库（mockttp / nock） | 快但重，与「运行期零依赖、构建期最小依赖」（`01` §2）相悖 |
| 顺序调用 + 放宽 p95 验收线 | 真实网络下 13 hunk × RTT 必击穿 `00` §3；放宽等于改上游 SSOT 为实现让路 |
