# 架构决策记录 (ADR)

> **权威**：格式与流程见 `dm-adr` skill 与 `dev-meta/docs/06` §4。ADR 是**决策日志**，不是设计文档——只写「为什么这么选」，不展开实现细节。

## 状态说明

- **提议中 (Proposed)**：正在讨论，尚未实施
- **已接受 (Accepted)**：已采纳并实施；**不可修改原文**，需变化时更新状态并创建新 ADR
- **已废弃 (Deprecated)**：不再适用
- **已替代 (Superseded by ADR-NNN)**：被新 ADR 替代，需双向交叉引用
